# Resume Generator using Python (ReportLab)

A simple, ATS-friendly resume generator built using **pure Python** with the **ReportLab** library.  
It generates a professional one-page PDF resume programmatically (no Flask, no Django, no JavaScript).

## ✨ Features
- Single-page, ATS-friendly resume layout  
- Clean sections: Summary, Skills, Projects, Education, Certifications  
- One-command PDF generation  
- No web frameworks, no JavaScript  
- Beginner-friendly Python project  

## 🛠 Tech Stack
- Python  
- ReportLab (PDF generation)
